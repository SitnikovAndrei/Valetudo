# Текстовая схема интерфейса Valetudo

Схема описывает [прототип](./preview.html) и показывает, как его разделы соотносятся с действующими маршрутами Valetudo. **Экран** — показан в макете; **обзор** — назван в меню или категории, но отдельный экран не нарисован; **условно** — доступен только при поддержке роботом. Данные прототипа вымышлены, команды не отправляются.

## Общая схема

```text
Прототип
├─ Панель просмотра: Карта / Настройки / Мобильный
│  └─ Светлая / тёмная тема; сценарий «Карта и зоны» / «Базовое управление»
├─ Карта и управление [экран, маршрут /]
│  ├─ Карта → выбор области → действие уборки
│  └─ Состояние и параметры робота
├─ Настройки [экран-каталог, реальные маршруты /options/*]
│  └─ Уборка / Карта / Подключения / Робот / Valetudo
├─ Мобильный [экран той же функциональности]
│  └─ Карта / Таймеры / Настройки / Ещё
└─ Все разделы [обзор] → существующие маршруты робота и сервиса
```

**Комментарий.** Переключатели экрана, темы и сценария возможностей нужны для просмотра макета. В рабочем приложении возможности определяются самим роботом. На мобильном «Ещё» открывает меню только из нижней навигации; в шапке дублирующей кнопки нет. На широком экране основные пункты находятся в боковой панели, полный каталог доступен через «Все разделы».

## Карта и управление

```text
Статус робота
├─ Модель, состояние, заряд
└─ Показатели текущего цикла [условно: если робот их отдаёт]

Карта
├─ Робот, база, маршрут во время уборки и комнаты [условно: наличие карты]
├─ Масштабирование в прототипе; перемещение — в рабочей карте
└─ Базовый сценарий → сообщение «Карта недоступна», управление сохраняется

Область действия
├─ Весь дом → обычный запуск
├─ Комнаты [условно] → выбор комнат на карте или кнопками → число проходов
├─ Зона [условно] → размещение демо-зоны на карте → число проходов
└─ К точке [условно] → размещение точки на карте

Действия
├─ На базе → Начать уборку; возврат недоступен
├─ Убирает → Пауза / Стоп / На базу
├─ Пауза → Продолжить / Стоп / На базу
├─ Остановлен → повторить действие или вернуться на базу
└─ К точке / Возвращается → отдельное состояние движения
```

**Комментарий.** В прототипе выбор на карте и число проходов остаются демонстрационными, а реальные координаты и допустимые значения должен проверять робот. Мощность всасывания, подача воды и «Не беспокоить» появляются только при соответствующей возможности. При реализации нужны состояния загрузки, ошибки, выполнения команды и подтверждение смены незавершённого действия на карте. Показатели текущего цикла не следует называть историей уборок.

## Настройки

```text
Уборка [экран]
├─ Мощность всасывания [условно] → пресеты конкретного робота
├─ Подача воды [условно] → пресеты конкретного робота
├─ Расписание → /valetudo/timers
└─ Не беспокоить [условно] → интервал, включение, Применить

Карта [условно, обзор, /options/map_management]
├─ Основная страница → сохранение, сброс и управление картой
├─ Сегменты /segments [условно] → границы и названия комнат
├─ Виртуальные ограничения /virtual_restrictions [условно] → запретные области
├─ Аннотации /annotations [условно] → метки на карте
├─ Карта покрытия /robot_coverage → отображение пройденной области
└─ Режим наблюдателя /spectator [условно] → поток карты

Подключения [обзор, /options/connectivity]
├─ Авторизация /auth → доступ к интерфейсу
├─ MQTT /mqtt → подключение к брокеру
├─ Обнаружение в сети /networkadvertisement → публикация устройства
├─ NTP /ntp → синхронизация времени
└─ Wi-Fi /wifi [условно] → параметры беспроводной сети

Робот [обзор, /options/robot]
├─ Системные параметры /system → функции самого робота
└─ Особенности модели /quirks → поведение конкретной реализации

Valetudo [обзор, /options/valetudo]
└─ Аналитика /analytics → параметры аналитики Valetudo
```

**Комментарий.** Пути дочерних страниц указаны относительно маршрута группы. «Не беспокоить» не означает гарантированный запрет уборки: эффект зависит от модели и прошивки. Статус сохранения должен появляться после ответа устройства; в прототипе кнопка «Применить» меняет только демонстрационный текст. Общего типа уборки «по умолчанию» и настройки доставки уведомлений в этом макете нет.

## Остальные разделы

```text
Робот
├─ Расходники /robot/consumables [условно] → состояние и обслуживание
├─ Ручное управление /robot/manual_control [условно] → движение робота
├─ Статистика /robot/total_statistics [условно] → суммарные показатели
└─ Камера /robot/camera [условно] → видеопоток при включённой функции

Сервис
├─ Таймеры /valetudo/timers → создание и управление расписанием
├─ Журнал /valetudo/log → системные события, не история уборок
├─ Обновление /valetudo/updater → обновление Valetudo
├─ Системная информация /valetudo/system_information → данные устройства
├─ AI Assistant /valetudo/ai → отдельный сервисный раздел
├─ Справка /valetudo/help → помощь
└─ О проекте /valetudo/about → сведения о Valetudo
```

**Комментарий.** Эти разделы перечислены в «Все разделы»; детальные экраны в прототипе не рисовались. Камера дополнительно зависит от конфигурации видеопотока. Для отсутствующей истории отдельных уборок нельзя подменять данные суммарной статистикой или журналом.

## Мобильный экран

```text
Шапка: название текущего экрана
↓
Статус робота и заряд
↓
Карта или сообщение о её недоступности
↓
Выбор области и дополнительные команды
↓
Закреплённая основная команда: запуск / пауза / продолжение
↓
Нижняя навигация: Карта / Таймеры / Настройки / Ещё
```

**Комментарий.** Мобильный экран использует те же правила доступности действий и возможности робота. «Ещё» открывает полный каталог; отдельной кнопки меню сверху нет. Содержимое карты и панель действий прокручиваются, нижняя навигация остаётся доступной.
