# Макет интерфейса Valetudo

Откройте `preview.html` в браузере или запустите локальный сервер:

```powershell
python -m http.server 8765 --directory frontend/design
```

Затем откройте `http://localhost:8765/preview.html`. В верхней панели переключаются три экрана, светлая/тёмная тема и сценарий возможностей робота. В режиме комнат выберите их на карте или кнопками, для зоны и точки нажмите на карту. Запуск становится доступен после выбора области. Пауза, остановка и возврат меняют только демонстрационное состояние: макет не связан с роботом.

`theme.css` содержит явные цветовые токены для обеих тем. Карта нарисована в SVG и использует те же токены. Макет не входит в рабочую сборку Vite и предназначен для согласования интерфейса перед реализацией.

| Роль | Светлая | Тёмная |
| --- | --- | --- |
| Фон | `#e9ede8` | `#101c19` |
| Поверхность | `#ffffff` | `#1d2d26` |
| Текст | `#19352c` | `#edf5ed` |
| Акцент | `#246e53` | `#86cba2` |

Общие принципы: карта занимает основную площадь, основные команды расположены перед дополнительными параметрами, настройки сгруппированы по задаче. На мобильном статус и карта находятся в одном потоке, а основная команда закреплена над нижней навигацией. «Все разделы» показывает существующие направления навигации; дополнительные экраны не прорисованы.

Соответствие элементов макета действующим компонентам, API и отсутствующим возможностям описано в [functional-mapping.md](./functional-mapping.md).

Общая структура экранов, состояний и всех разделов с комментариями приведена в [text-scheme.md](./text-scheme.md).

Прототип изолирован от рабочего интерфейса в `frontend/src/`.
